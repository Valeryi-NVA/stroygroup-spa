# СтройГрупп — браузерная SPA

Это отдельная vanilla JavaScript-версия, построенная на основе интерфейса
корневого `index.html`. Модули — нативные ES-модули браузера, без сборщика и
внешних зависимостей; остальной исполняемый код использует синтаксис ES5.
Она не вызывает API и сохраняет модель в браузере
под ключом `stroy_model_v2`.

## Запуск

Откройте папку `browser-spa` в VS Code. Запускайте `index.html` через
расширение для статической раздачи файлов (например, Live Server), затем
откройте его локальный адрес. ES-модули браузера требуют HTTP(S), поэтому
не открывайте страницу двойным щелчком как `file://`.

## Публикация на GitHub Pages

В репозитории настроен workflow `.github/workflows/pages.yml`: после push в
ветку `main` он публикует содержимое корня репозитория. Чтобы опубликовать
именно эту SPA, содержимое папки `browser-spa` должно быть корнем отдельного
репозитория. В настройках репозитория выберите **Settings → Pages → GitHub
Actions**. Ссылка появится в разделе Pages после успешного запуска workflow.

На бесплатном тарифе GitHub Pages доступен для публичных репозиториев.
Публикация не делает данные общими: записи сохраняются в localStorage каждого
браузера отдельно. Вход и хеширование пароля демонстрационные; приложение не
подходит для хранения реальных персональных или финансовых данных и не имеет
серверной базы, синхронизации, управления доступом на сервере или резервного
копирования.

Демо-вход:

```text
Телефон: +79000000000
Пароль: admin
```

Для просмотра ролей в демонстрационных данных пароль остальных пользователей
`1234`. При регистрации новая запись получает роль `worker`.

## Данные и бухгалтерия

При первом открытии загружается демонстрационный набор. Для сброса используйте
«Настройки → Сбросить демо-данные». Это удалит сохранённую локальную модель
в текущем браузере после подтверждения.

Финансовая сводка показывает фактические расходы по объектам и категориям.
Поступления вынесены в отдельный список и не входят в расходный итог.
Зарплата считается отдельно на вкладке «Зарплата»; в расходы объектов она
не включается. Табель учитывается в днях, включая доли дня.

Данные находятся только в localStorage текущего браузерного профиля и не
синхронизируются между устройствами. Хеш FNV-1a здесь демонстрационный и
не является безопасным хранением паролей. Не храните реальные персональные
или финансовые данные в этой демо-версии.
